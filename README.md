# Oladeinde-abubakar-korewafunmi_mechatronics_quiz_app
A Python-based Mechatronics Quiz Application.
Mechatronics Quiz Application

What it does

The Mechatronics Quiz Application is a Python program designed to test users' knowledge of basic computer and engineering concepts.

It displays multiple-choice questions, checks answers, calculates scores and automatically assigns grades.

How to run it

Install Python 3 and run:

python mechatronics_quiz.py

Sample Output

Correct Answers: 5

Wrong Answers: 0

Percentage: 100%

Grade: A

My Own Twist

I added three extra features:

1. Instant explanations for incorrect answers.
2. Automatic performance grading.
3. An option to retake the quiz.

What I Learned

I learned how to use Python functions, lists, loops, conditional statements and input validation to develop a working application.
